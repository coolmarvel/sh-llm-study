# 프로젝트 브리프: sh-llm-study

## 한 줄 정의

LLM 을 처음 배우는 자바 배경 개발자(이성현)가, 개념을 챕터별로 익히면서 **CPU 만으로 소형 한글 GPT 를
밑바닥부터 직접 구현·학습**하고, 그 과정을 교재(PDF)와 웹 대시보드로 남기는 학습 프로젝트.

## 문제와 사용자

- **문제**: LLM 이 어떻게 동작하는지 원리를 모른다. 토큰·임베딩·어텐션·Transformer·학습·생성이
  각각 무엇이고 어떻게 이어지는지를, 남의 설명이 아니라 **내 손으로 짠 코드**로 확인하고 싶다.
  GPU 가 없어 대형 모델은 다룰 수 없고, 학습 자료는 대부분 영어·수학 위주라 진입 장벽이 높다.
- **사용자 유형**: 단일 사용자(제작자 본인). 역할이 두 가지로 나뉜다.

| 유형 | 이 프로젝트에서 하는 일 |
|---|---|
| 학습자 | 챕터 순서대로 개념 문서를 읽고, 노트북을 실행·수정하며 실험한다. 마지막에 PDF 교재로 복습한다 |
| 구현자 | 각 챕터의 코드를 `src/` 패키지로 축적해 최종적으로 학습·생성이 되는 GPT 한 벌을 완성한다 |

## 핵심 시나리오 (v1.0 에 반드시 되어야 하는 것)

1. 학습자가 챕터 문서를 읽고 노트북을 CPU 에서 실행해, **각 개념이 코드로 무엇인지** 눈으로 확인한다
   (토큰 → 임베딩 → 어텐션 → Transformer → 학습 → 생성 순서).
2. 구현자가 문자 단위 토크나이저와 바이그램 모델부터 시작해, **BPE 토크나이저·MLP·어텐션·GPT** 를 순서대로 직접 구현한다.
3. 구현자가 한글 공개 텍스트 코퍼스로 수백만~수천만 파라미터 GPT 를 **이 PC(CPU 16코어, RAM 7.6GB)에서 수십 분~수 시간 안에 학습**시키고 체크포인트를 저장한다.
4. 학습자가 학습된 모델에 한글 프롬프트를 주면 **문법적으로 그럴듯한 한글 문단이 이어져 생성**된다 (temperature·top-k 조절 포함).
5. 학습자가 모든 챕터를 마친 뒤 **PDF 교재 한 권**(개념 설명 + 코드 카드 + 자바 비교)을 바탕화면에서 열어 복습한다.
6. 학습자가 웹 대시보드에서 **손실 곡선·어텐션 맵·토큰별 생성 확률**을 보며 모델 내부를 시각적으로 이해한다.

## 제약

- **플랫폼/형태**: WSL2(Ubuntu) 로컬, **CPU 전용**(NVIDIA GPU 없음). 노트북 + Python 패키지 + 웹 대시보드(도커).
- **기간/리듬**: 기한 없음. 챕터 단위로 진행하며 한 챕터는 한 세션 안에 끝나는 크기로 자른다.
- **비용**: 유료 API·클라우드 GPU 없음. 전부 로컬·무료.
- **저장**: 코드는 WSL(`~/sh-llm-study`), 코퍼스·체크포인트는 D 드라이브(`/mnt/d/sh-llm-data`, `data/` 심볼릭 링크)에 두어 윈도우 탐색기로 볼 수 있게 한다. 총 5GB 이내.
- **코퍼스**: 저작권 문제 없는 한글 공개 텍스트만 (퍼블릭 도메인 문학, CC 라이센스 위키 등).
- **기타**: 혼자 쓰는 학습 도구. 인증·결제·배포 없음.

## 성공 기준

- "**한글 문장을 이어서 말이 되게 생성** + 모든 챕터를 내 말로 설명할 수 있다" — 사용자 선언 기준.
- 구체적으로: 내가 학습시킨 모델이 "옛날 옛적에" 같은 프롬프트를 받아 문법적으로 그럴듯한 한글 문단을 이어가고,
  각 챕터의 핵심 질문(예: "어텐션은 왜 필요한가", "LayerNorm 은 뭘 하나")에 코드 위치를 짚으며 답할 수 있다.

## 범위 밖 (이번에 안 하는 것)

- 공개 대형 모델(Llama·Qwen 등) 파인튜닝·서빙 — 개념 지도만 마지막 챕터에서 다루고 구현하지 않는다.
- GPU·분산 학습·클라우드 학습.
- 대화형 챗봇·RAG·도구 호출 등 제품 기능.
- 실제 서비스 배포·인증·다중 사용자.
