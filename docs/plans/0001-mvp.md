# MVP 계획: 챕터 로드맵

브리프(`docs/brief.md`)의 시나리오 1~6 을 마일스톤으로 자른다. 상태: `[ ]` 미착수 · `[~]` 진행 중 · `[x]` 완료 · `[?]` 결정 필요.

한 챕터 = 문서 1개(`docs/book/NN-*.md`) + 노트북 1개(`notebooks/NN-*.ipynb`) + 패키지 모듈(`src/shllm/*.py`) + 테스트.
모든 챕터는 **이 PC 의 CPU 에서 노트북 전체 실행이 10분 이내**로 끝나야 한다 (학습 챕터는 "짧은 학습" 셀과 "긴 학습" 스크립트를 분리).

## M0: 킥오프 + 뼈대 (며칠 안에 만져볼 수 있는 것)

- [x] 프로젝트 생성, 템플릿, 브리프, ADR-0002
- [x] `uv` 환경 + PyTorch CPU + Jupyter, `ruff`/`pytest` 검증 통과
- [x] `src/shllm/` 패키지 뼈대 + 코퍼스 다운로드 스크립트(`scripts/download_corpus.py`)
- [x] 0장 문서·노트북: 환경 확인, LLM 큰 그림, 자바 개발자를 위한 Python/PyTorch 최소 지식
- [x] `notebooks/` 전체 실행(`nbconvert --execute`) 이 검증 명령에 포함

## M1: 텍스트를 숫자로 (1~2장)

- [x] 1장 문자 토크나이저 + 바이그램 통계 모델: "다음 글자 확률표"만으로 한글 생성 → 왜 문맥이 필요한지 체감
- [x] 2장 BPE 토크나이저 직접 구현 (`shllm/tokenizer.py`): 유니코드·한글 음절/자모 이슈, 어휘 크기 실험, 저장/로드, `data/tokenizers/bpe-8192.json`

## M2: 신경망과 임베딩 (3~4장)

- [x] 3장 임베딩: 룩업 테이블, 위치 임베딩, 세어서 만든 벡터(PPMI+SVD) 시각화 (`shllm/embedding.py`), 학습된 벡터 시각화는 7장 학습 후 재방문
- [x] 4장 신경망 기초: 스칼라 autograd(`autograd.py`)·NumPy 역전파(`numpy_lm.py`)·PyTorch MLP 언어모델(`mlp.py`)

## M3: 어텐션과 Transformer (5~6장)

- [x] 5장 셀프 어텐션 밑바닥 구현: Q/K/V, 마스킹, 멀티헤드 (`shllm/attention.py`)
- [x] 6장 Transformer 블록 → GPT 조립: LayerNorm·잔차·FFN, 파라미터 수 세기 (`shllm/model.py`)

## M4: 학습과 생성 (7~8장) ← **v1.0 성공 기준이 걸린 마일스톤**

- [x] 7장 학습 루프: 데이터 로더, AdamW, LR 스케줄, 손실 곡선, 체크포인트, CPU 스레드 최적화 (`shllm/train.py`, JSONL 로그)
- [x] 8장 텍스트 생성: temperature·top-k·top-p·반복 억제 (`shllm/generate.py`), 한글 프롬프트 이어쓰기 (품질은 소형 코퍼스 한계, 노트북 08)
- [x] 긴 학습 스크립트(`scripts/train.py --config configs/small-cpu.yaml`), 6.8M 파라미터, 2,500스텝 약 1시간 (코퍼스 49만 토큰이라 더 키우면 과적합 → 데이터 확장이 먼저)

## M5: 평가와 그 다음 (9~10장) + 교재

- [x] 9장 평가: perplexity·bits/char, 모델 크기 vs 손실(스케일링 맛보기), 어휘 4096/8192 비교 (`shllm/eval.py`)
- [x] 10장 그 다음 지도: 파인튜닝·RLHF·RAG, 개념 + 미니 SFT 시연 (`shllm/sft.py`, 작품 목록 질문-답 80개)
- [x] `docs/book/` → PDF 한 권 빌드(`scripts/build_book.py`, weasyprint) → 바탕화면 전달, 1장 시점에 앞당겨 구현, 챕터마다 재빌드

## M6: 웹 대시보드

- [x] oh-my-design 설치(`.claude/skills/omd-*`) + `DESIGN.md` (Linear 레퍼런스에서 손으로 파생, `/omd:init` 정식 패키지는 todo P3)
- [x] FastAPI: 실험 목록·손실 로그·체크포인트 로드·생성 API·어텐션 맵 API (`dashboard/api/main.py`)
- [x] React(Vite·TS·Tailwind): 손실 곡선, 어텐션 히트맵, 토큰별 확률 생성 뷰 (`dashboard/web/`)
- [x] 도커 컴포즈로 8082 포트, Playwright 데스크톱(1360)+모바일(400) 뷰포트 검증 (2026-09-16)
- [x] Docker Desktop WSL 통합 활성화 (2026-09-16 확인: `docker` 29.7 동작)
